# Journal

Short factual notes on what has shipped in the SocialGravity proof layer.

One rule, and it is the only thing that makes this worth reading: **every post ends in a command
or a URL that returns a real result.** If a claim cannot be checked from outside the company, it
does not get a post. If a check is going to fail or come back inconclusive, the post says so and
shows the output anyway.

No roadmap posts. No posts about things that are going to be true.
